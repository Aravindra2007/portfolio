# Aravind Kumar K - Portfolio

A professional portfolio website showcasing the skills, projects, and achievements of Aravind Kumar K, a Computer Science undergraduate at VIT-AP University.

## Features

- **Hero Section with Background Image**: Full-screen background photo with overlay and centered content
- **Responsive Design**: Works on all device sizes
- **Modern UI**: Clean, professional interface with smooth animations
- **Interactive Elements**: Animated counters, hover effects, and interactive components
- **Easy Navigation**: Clear navigation between all sections
- **Performance Optimized**: Efficient CSS and JavaScript

## Structure

## Pages

1. **Home/Landing Page** (`index.html`) - Features a full-screen background image with your name, tagline, call-to-action buttons, stats grid, and quick navigation cards
2. **About** (`about.html`) - Detailed background, education, and professional summary
3. **Skills** (`skills.html`) - Technical skills organized by category
4. **Projects** (`projects.html`) - Showcase of projects with descriptions and technologies
5. **Achievements** (`achievements.html`) - Accomplishments, recognitions, and milestones
6. **Contact** (`contact.html`) - Contact information and call-to-action

## Local Development

To view the portfolio locally:
1. Clone or download this repository
2. Open any HTML file in your web browser
3. No build process or dependencies required

## Deployment

This is a static website that can be hosted on any static hosting service:
- GitHub Pages
- Netlify
- Vercel
- AWS S3
- Or any traditional web hosting
